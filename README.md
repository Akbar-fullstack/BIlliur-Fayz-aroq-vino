🥂 Billur Fayz — сайт по вино-водочной продукции
Описание проекта:  
Billur Fayz — это веб‑сайт, разработанный для представления ассортимента вино‑водочной продукции компании. Проект демонстрирует современный подход к UI/UX, адаптивный дизайн и удобную навигацию для пользователей.

Основные особенности:

Каталог продукции с карточками и фильтрацией

Интерактивные модальные окна для подробного описания товаров

Адаптивная верстка для всех устройств

Использование современных технологий (Tailwind CSS, JavaScript)

SEO‑оптимизация для продвижения бренда

Технологии:

HTML5, CSS3, Tailwind CSS

JavaScript (модальные окна, динамические элементы)

Возможность интеграции с CMS (WordPress)

Цель проекта:  
Создать удобный и эстетичный сайт, который подчеркивает премиальность продукции Billur Fayz и помогает компании привлекать новых клиентов.
